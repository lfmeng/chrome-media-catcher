📝 使用说明

• SVG 格式可无损缩放到任意尺寸
• 可用于进一步编辑或导出其他格式
• 可用浏览器直接打开预览
• 可用矢量图软件（如 Illustrator、Figma）编辑

🔧 使用方法

1. 重新生成图标

python3 generate-icons.py

2. 查看效果

在 Chrome 中重新加载插件：chrome://extensions/ → 点击"重新加载"按钮

3. 测试占位图

打开插件，捕获图片，故意输入一个错误的图片URL，查看占位图是否显示

4. 自定义设计

编辑 generate-icons.py 脚本，修改颜色、尺寸或图形元素
